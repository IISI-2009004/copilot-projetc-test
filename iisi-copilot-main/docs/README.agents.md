# 🤖 Custom Agents 自訂代理

GitHub Copilot 的自訂代理，使用戶和組織能夠透過簡單的基於文件的配置輕鬆地「自訂」其 Copilot 編碼代理 (CCA)。

## 如何使用自訂代理

**安裝步驟：**

- 按一下要使用的代理程式的 VS Code 或 VS Code Insiders 安裝按鈕。
- 下載 *.agent.md 檔案並將其新增至您的儲存庫。

**MCP 伺服器設定：**

- 每個代理程式可能需要一個或多個 MCP 伺服器才能正常運作。
- 點擊 MCP 伺服器即可在 GitHub MCP 註冊表中查看。
- 請按照指南將 MCP 伺服器新增至您的儲存庫。

**啟動/使用方法：**

- 透過 VS Code 聊天介面存取已安裝的代理，在 CCA 中指派代理，或透過 Copilot CLI（即將推出）指派代理程式。
- 代理將能夠存取已配置的 MCP 伺服器上的工具。
- 請遵循代理商的具體說明以獲得最佳使用效果。
