# 🔌 Plugins 插件

精選的相關代理和技能插件，圍繞特定主題、工作流程或用例進行組織。插件可直接透過 GitHub Copilot CLI 或 VS Code 安裝。

> _Awesome Copilot_ 是一個預設的插件市場 ——在 Copilot CLI 或 VS Code 中均無需設定。

## 如何使用插件

**瀏覽插件：**

- ⭐ 精選外掛程式會高亮顯示並置於清單頂部。
- 探索將相關自訂項目分組的主題插件。
- E每個插件都包含針對特定工作流程的代理和技能。
- P插件使得針對特定場景採用全面的工具包變得容易。

**在 Copilot CLI 中尋找並安裝：**

- 在互動式 Copilot 會話中瀏覽市場：`/plugin marketplace browse awesome-copilot`
- 安裝插件：`copilot plugin install @awesome-copilot`

**在 VS Code 中尋找並安裝：**

- 開啟擴展搜尋視圖，輸入 `@agentPlugins` 以瀏覽可用的插件。
- 或打開命令面板並運行`Chat:Plugins`
