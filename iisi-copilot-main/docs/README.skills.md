# 🎯 Agent Skills 代理人技能

代理人技能是包含指令和捆綁資源的獨立資料夾，用於增強人工智慧執行特定任務的能力。根據[智能體技能規範](https://agentskills.io/specification) ，每個技能都包含一個 SKILL.md 文件，其中包含智能體按需加載的詳細說明。

技能與其他基本要素的不同之處在於，它支援捆綁資源（腳本、程式碼範例、參考資料），代理程式在執行專門任務時可以利用這些資源。

## 如何運用代理人技能

**包含內容：**

- 每個技能都是一個資料夾，其中包含一個 SKILL.md 指令檔。
- 技能可能包括輔助腳本、程式碼範本或參考資料
- 技能遵循代理人技能規範，以實現最佳相容性。

**何時使用：**

- 技能型工作流程非常適合複雜、可重複的工作流程，並且能夠從資源整合中獲益。
- 當您需要程式碼範本、輔助工具或參考資料以及相關說明時，請運用您的技能。
- 技能提供漸進式揭露－僅在執行特定任務需要時才載入

**用法：**

- 瀏覽下方技能表，找出相關能力
- 使用 GitHub CLI 安裝技能： `gh skills install github/awesome-copilot <skill-name>` （需要 [GitHub CLI v2.90.0+](https://github.blog/changelog/2026-04-16-manage-agent-skills-with-github-cli/) ）
- 或手動將技能資料夾複製到本機技能目錄。
- 在提示中提及相關技能，或讓代理人自動發現它們。
